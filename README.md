# ml_project2
In this repository the files necessary to run the binary classification problem of: "Prediction of Harmful Algal Bloom (HAB)" are present. The most important files are the following:

- training_code.py: This is the main delivery file, where data traverses from a given database into training two different classification models that are compared with many metrics. Those are Multi-Layer Perceptron and Logistic Regression.
- complete.py: This file is similar to the one previously mentioned, but contains a much clearer thought and iteration process of the six models chosen for comparison.
